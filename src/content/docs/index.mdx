## What this site is

Thought Base is the public working notebook of an **Enterprise AI Transformation Architect** targeting regulated, complex enterprises — primarily BFSI and Healthcare/Pharma, delivered through Global Capability Centers (GCCs) in India.

It is not a blog of opinions. Every page here is a **reusable artifact**: a control matrix, a risk-tiering intake, a reference architecture, a FinOps model, a decision framework. The thesis is simple:

> **Legal requirements → enterprise controls → operational evidence → cost of failure.**

If a regulation cannot be expressed as an enforceable platform control with automated evidence and a cost-of-failure number, it is a policy document, not governance. This site is about making it the former.

## How to use this site

Every artifact page ships a **TL;DR box**, a **framework**, and a **template you can copy**. Sections are ordered as a reading path: Governance → Architecture → FinOps → Playbooks → Control Library → India → Writing → Resources. If you only have 10 minutes, read the Control Framework.

This is a living site. Artifacts are versioned in place and updated as regulations (RBI/SEBI draft rules, DPDP rules, EU AI Act delegated acts) and practice evolve. No "last updated" stamps are used; material changes are noted inline.
:::
